Flying circus

Jeu pour iPhone

Deux clowns tiennent un filet sous le chapiteau : déplacez-les pour rattraper les trapézistes qui tombent et les faire rebondir jusqu'au trapèze final.

Attention : plus la partie avance, plus les trapézistes tombent vite.

Assistance

Une question, un problème ou une idée ? Écrivez-nous ici (un compte GitHub gratuit est nécessaire). Indiquez le modèle de votre iPhone et sa version d'iOS si vous signalez un problème.

Questions fréquentes

Comment jouer ? Touchez les flèches gauche et droite pour déplacer les clowns. START lance la partie, RAZ remet le score à zéro, SON coupe ou remet le son.

Faut-il une connexion internet ? Non, le jeu fonctionne entièrement hors ligne.

Le jeu collecte-t-il des données ? Non. Voir la politique de confidentialité.
